처음 사용하는 분

1. 휴대폰에 아이콘 만들기

앱을 설치하지 않고, 홈 화면에 아이콘을 추가해서 앱처럼 씁니다. 아이콘은 남색 바탕에 빨강·노랑·초록 신호등과 “ANDON” 글자입니다.

안드로이드 (삼성 등) · Chrome

  1. 위 주소(또는 QR)를 Chrome으로 엽니다.
  2. 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 (또는 앱 설치).
  3. 추가를 누르면 홈 화면에 ANDON 아이콘이 생깁니다.

아이폰 · Safari

  1. 위 주소(또는 QR)를 Safari로 엽니다.
  2. 아래쪽 공유 버튼(□↑) → 홈 화면에 추가.
  3. 이름이 “ANDON”인지 확인하고 추가를 누릅니다.

2. 로그인 · 비밀번호

  1. 로그인
    아이디 칸에 사번(사번이 없는 분은 회사 이메일), 비밀번호 칸에 시스템 담당자 오영환 책임(QC)에게 받은 임시 비밀번호를 넣습니다. 한 번 로그인하면 일주일 동안 유지됩니다.
    로그인하면 GL · SV는 바로 ANDON 호출 화면, 조치부서 담당자는 내 부서 ANDON 화면이 열립니다.
  2. 비밀번호 바꾸기
    처음 로그인하면 오른쪽 위 내 이름 → ‘내 정보’ → 비밀번호 변경에서 본인 비밀번호(8자 이상, 영문+숫자)로 바꿔 주세요.
  3. 계정이 없는 분
    시스템 담당자 오영환 책임(QC)에게 계정 등록을 요청하세요. 품질팀 등 명단에 없는 분은 회원가입에서 이름·이메일·비밀번호·내 부서를 넣어 직접 만들 수 있습니다.
역할은 관리자가 정합니다. 가입하면 모두 ‘담당자’로 시작합니다. GAP 리더·감독자(SV)는 관리자가 역할을 바꿔야 ANDON을 호출할 수 있습니다. 비밀번호를 잊으면 시스템 담당자 오영환 책임(QC)에게 재설정을 요청하세요.

3. 카카오톡 알림 연결

  1. ‘내 정보’ 아래 카카오 알림 연결
  2. 본인 카카오 계정으로 로그인 후 ‘카카오톡 메시지 전송’에 체크하고 동의
  3. 카카오톡 ‘나와의 채팅’에 확인 메시지가 오면 완료
    상태가 ‘✔ 연결됨’으로 바뀝니다. 테스트 보내기로 다시 확인할 수 있습니다.

알림은 본인 ‘나와의 채팅’으로만 갑니다. 친구 목록·대화 내용은 가져오지 않으며, 연결 해제로 언제든 끌 수 있습니다.

GAP 리더 · 감독자

4. ANDON 호출하기

작업자가 해결하지 못한 문제는 GAP 리더를 부르고, GAP 리더가 상황을 보고 조치부서를 호출합니다. GL · SV는 로그인하면 바로 호출 화면이 열립니다 (다른 화면에서는 첫 화면의 ANDON 호출). 보통 2~3번 누르면 끝납니다.

  1. 라인 누르기 (담당 라인이 하나면 자동 선택 — 생략)
    맨 위 내 담당 라인에서 고릅니다. 다른 라인은 다른 라인 보기 (전체).
  2. 상황 누르기
    아래 표의 상황 버튼을 누르면 이상 유형, 조치부서, 받는 사람(부서원 전원 · SV는 그 라인 감독자)이 자동으로 정해집니다. 여러 상황을 함께 누를 수도 있습니다.
  3. 화면 아래 ANDON CALL 누르기
    버튼 위에 “FRT · Robot Fault → MT 3명”처럼 누구에게 가는지 보입니다. ANDON 번호가 표시되면 완료 — 현황판에 바로 뜨고 선택된 사람에게 카카오톡이 갑니다.
바꾸고 싶을 때만 ‘세부 설정’을 펼치세요. 이상 유형, 조치부서 추가·삭제, 받는 사람 빼기·더하기, 내용 입력을 할 수 있습니다 (사진은 쓰지 않습니다). 상황표에 없는 문제는 세부 설정에서 이상 유형·조치부서를 직접 고르고 내용을 적으면 됩니다.

품질 물류 설비 안전 생산·기타

오른쪽 ‘ACTIVE ANDON’ 목록은 오래된 순서로 경과 시간을 보여줍니다. 칸이나 목록을 누르면 처리 화면이 열립니다. 이력 / 통계에서는 지난 ANDON과 부서별 건수·처리 시간을 볼 수 있습니다.

이력은 1년간 보관 후 삭제됩니다. ‘이력 / 통계’ 화면의 CSV 저장에서 기간을 골라 PC에 저장할 수 있습니다 (로그인 필요, 엑셀로 열림).
현황판 담당 · 설치하는 분

7. 현황판 PC 설정

현장 대형 모니터의 미니 PC를 켜면 바로 현황판만 꽉 차게 나오도록(키오스크) 한 번만 설정합니다. 현황판은 공개 화면이라 ANDON 로그인이 필요 없습니다.

  1. Chrome 설치 · 모니터 해상도
    Chrome을 설치하고, 디스플레이 해상도를 1920 × 1080으로 맞춥니다 (4K 모니터는 배율 200%).
  2. 키오스크 바로가기 만들기
    바탕화면 Chrome 바로가기 → 오른쪽 클릭 → 속성 → ‘대상’ 맨 끝에 한 칸 띄우고 아래를 붙여 넣습니다.
    --kiosk https://forvia-yeongcheon-andon.vercel.app/dashboard
  3. 켜면 자동 실행
    Win + R → shell:startup 입력 → 열린 폴더에 위 바로가기를 복사합니다.
  4. Windows 자동 로그인
    PC를 켜면 비밀번호 없이 바탕화면까지 가도록 설정합니다 (회사 IT 정책 확인).
  5. 절전 끄기
    설정 → 시스템 → 전원 → 화면 끄기 · 절전 모드를 ‘안 함’으로 합니다.
  6. 정전 후 자동 켜짐
    BIOS에서 AC Power On / Restore on AC Power Loss를 켭니다.
  7. LTE 데이터 절약
    LTE 공유기 연결을 Windows에서 ‘데이터 통신 연결(종량제)’로 설정하고, Windows 업데이트 재시작 시간을 근무 외 시간으로 지정합니다.
현황판은 상시 켜 두세요. 현황판이 켜져 있는 동안 서버가 1분마다 ‘2시간 미완료’를 확인해 에스컬레이션 카카오톡을 보냅니다. 화면은 5초마다 새로 고쳐지고, 연결이 20초 이상 끊기면 화면 위에 경고가 표시됩니다. 점검할 때는 Alt + F4로 현황판을 닫을 수 있습니다.

8. 이럴 땐 이렇게

ANDON 호출 화면에 “호출할 수 없습니다”가 나와요

호출은 GAP 리더·감독자 역할만 할 수 있습니다. 시스템 담당자 오영환 책임(QC)에게 역할 변경을 요청하세요.

받는 사람 목록에 우리 부서 사람이 없어요

아직 가입하지 않은 사람은 목록에 나오지 않습니다. 가입할 때 부서를 정확히 골랐는지도 확인하세요.

카카오톡 알림이 안 와요

‘내 정보’에서 카카오 알림 상태가 ‘✔ 연결됨’인지 확인하세요. ‘⚠ 다시 연결 필요’면 다시 연결합니다. 호출할 때 내가 받는 사람으로 선택됐는지도 GAP 리더에게 확인하세요.

처리 화면에 접수 버튼이 없어요

로그인했는지, 그리고 그 ANDON이 내 부서로 호출됐는지 확인하세요. 다른 부서 ANDON은 볼 수만 있습니다.

화면 위에 “서버 연결 끊김”이 보여요

네트워크를 확인하세요. 다시 연결되면 자동으로 최신 상태로 바뀝니다.

비밀번호를 잊었어요

시스템 담당자 오영환 책임(QC)에게 재설정을 요청하면 임시 비밀번호를 받습니다. 로그인 후 ‘내 정보 → 비밀번호 변경’에서 바꾸세요.
